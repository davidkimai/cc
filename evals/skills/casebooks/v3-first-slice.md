# Skills V3 First-Slice Casebook

This casebook documents the first deterministic Skills V3 slice. It is intentionally fixture-level evidence.

## Failure / Edge Classes

- Baseline thread tasks should not use `epistemic-routing`.
- Marketing or press-release requests should not use ACP skills to overclaim deliberative validity.
- Missing source references should force review instead of low-risk omission conclusions.
- Canonical protocol vocabulary drift must be flagged instead of documented as compatibility.
- Public-hearing benchmark evidence supports a scale path, not real institutional validation.

## Reviewer Use

Use the generated `failure-casebook.md` from each run to see which fixture expectations failed and which negative controls remain covered.
