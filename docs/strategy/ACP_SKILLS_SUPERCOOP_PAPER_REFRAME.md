# ACP Skills Supercooperation Paper Reframe

Status: draft paper-facing framing note  
Audience: manuscript editor, title/abstract/introduction owner

## Core move

Introduce ACP Skills in the opening paragraph or two of the abstract and introduction, not as an add-on but as a **constitutional procedural layer for public reasoning under bounded attention**.

## Selected title

The selected working paper title is:

- `Collective Deliberation Is a Skill Issue`

Backup title directions if a stricter venue tone or reviewer audience requires them:

- `Public Reasoning Is a Skill Issue`
- `Public Reasoning Is an Attention Problem`

## Abstract opening options

### Option A: memetic but defensible
Collective deliberation is not only a model problem; it is a procedural skill problem. We present ACP, a protocol-first system for AI-assisted public reasoning under bounded attention, and ACP Skills, an inspectable procedural layer that helps route attention, preserve disagreement, catch omissions, enforce claim boundaries, and escalate uncertain cases before release.

### Option B: more serious / workshop-safe
AI-assisted public reasoning under overload requires more than strong models or generic summarization. It requires reusable procedural safeguards for routing, explanation, omission detection, contestability review, and abstention. We present ACP, a protocol-first coordination system, and ACP Skills, an inspectable constitutional skills layer for bounded collective deliberation.

## Introduction spine

Recommended order:

1. Bounded attention is the root problem in collective deliberation.
2. Compression under overload creates specific failure modes: false consensus, omission, contestability loss, overclaiming, unsafe release.
3. These failures are not solved by model scale alone; they are procedural skill problems.
4. ACP provides protocol semantics and implementation surfaces.
5. ACP Skills provide the reusable constitutional workflow modules that govern how the system routes, explains, critiques, abstains, and packages evidence.
6. The contribution is both infrastructural and empirical: a protocol-plus-skills stack with bounded study evidence.

## Sentences worth carrying into the manuscript

- `ACP Skills are not a prompt library; they are inspectable procedural interventions over protocol-defined deliberation objects.`
- `The skills layer is where bounded norms enter the workflow without being hidden inside model weights.`
- `The strongest current contribution is failure-mode control under bounded attention, not a claim of solved deliberation.`
- `The relevant question is not whether AI can deliberate for the public, but whether it can help institutions compress public input without erasing disagreement, uncertainty, or contestability.`

## Claim discipline for the paper

The manuscript can now more confidently claim:

- skills as procedural interventions
- inspectable failure-mode safeguards
- cross-domain civic compositions
- portability-oriented procedural sharing

The manuscript should still avoid claiming:

- field efficacy
- operator utility without human review
- fairness solved
- institutional legitimacy by default
- broad superiority across all settings
