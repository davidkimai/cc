# ACP Skills V2 Audit

Status: current suite audit against `RELAY_BLOCKS_SKILL_MATURITY_STANDARD.md`
Owner: senior researcher / engineer

## Audit Method

The audit classifies the suite against the Skills V2 maturity standard, then requires the mandatory upgrade set to pass the automated `skills:audit` gate.

The audit checks:

- registry and manifest consistency
- maturity metadata
- required S3/S4 directories
- required `SKILL.md` sections
- examples covering happy path, failure path, escalation, and anti-pattern
- eval hooks
- composition entrypoints

## Baseline Finding

The pre-V2 suite had a real skeleton but most skills were too thin to count as robust. Several blocks had executable helpers, but few had casebooks, escalation guidance, explicit trust notes, or skill-quality rubrics.
