## Scenario recap

A planning commission needs ACP to route public hearing concerns for a mixed-use development near a transit corridor.

## Evaluation goal

Check whether ACP turns a crowded hearing into a small set of decision-relevant issue buckets without erasing procedural fairness.

## Evidence to capture

- routed issue buckets
- chair opening script
- factual versus value-based classification
- follow-up questions left open

## Scoring rubric

- `0` the routing is generic or over-compressed
- `1` some useful buckets exist but the procedural structure is weak
- `2` the routing is focused, fair, and clearly tied to hearing decisions

## Failure modes

- too many buckets to be useful
- testimony is flattened into one summary
- the chair script sounds partisan or defensive
- the prompt invents local facts to fill gaps

## CORDA legibility checks

Ask whether a CORDA reviewer can see:

- how ACP reduced hearing overload
- how it preserved decision structure
- what would still need human judgment after routing

If the answer is no, the pack is not yet ready for a live civic demo.
