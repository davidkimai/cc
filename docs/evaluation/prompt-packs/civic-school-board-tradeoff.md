## Scenario recap

A school board must choose between expanding counseling staff and keeping oversubscribed after-school tutoring slots.

## Evaluation goal

Check whether ACP can preserve a student-centered tradeoff while producing language suitable for families and board members.

## Evidence to capture

- recommendation
- family-facing explanation
- comparison point supporting the choice
- follow-up metric for the next term

## Scoring rubric

- `0` the output hides the tradeoff or reads like a generic program description
- `1` the choice is visible but the explanation is incomplete
- `2` the choice is clear, honest about the downside, and ready for board use

## Failure modes

- vague student impact language
- the recommendation avoids choosing
- the explanation is too technical for families
- no measurable follow-up is named

## CORDA legibility checks

Ask whether a CORDA reviewer can see:

- what ACP is deciding
- why the choice is hard
- how the result could be used in a board packet

If those answers are unclear, the pack needs revision.
