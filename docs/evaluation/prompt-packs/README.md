# ACP Evaluation Prompt Packs

This directory contains the evaluation companions for the civic and governance prompt packs.

Pack rules:

- each file mirrors a pilot pack with the same basename
- each pack states what evidence to capture and how to judge the cycle
- each pack should support comparison across runs without rewriting the scenario

Current set:

- `civic-budget-reallocation.md`
- `civic-public-hearing-routing.md`
- `civic-school-board-tradeoff.md`
- `civic-emergency-response-brief.md`
- `civic-procurement-oversight.md`
