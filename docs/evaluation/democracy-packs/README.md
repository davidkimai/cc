# ACP Evaluation Democracy Packs

This directory contains the evaluation companions for the civic and governance democracy packs.

Pack rules:

- each file mirrors a pilot pack with the same basename
- each pack states what evidence to capture and how to judge the cycle
- each pack should support comparison across runs without rewriting the underlying decision pattern

Current set:

- `civic-participatory-budget-prioritization.md`
- `civic-public-hearing-routing.md`
- `civic-council-agenda-triage.md`
