# Missingness Review

Use this note when turning pilot missingness into an evaluation decision.

## Review steps

1. Read the operator handoff.
2. Inspect the export manifest.
3. Read the missingness log in order.
4. Decide whether the gap affects inclusion, interpretation, or neither.
5. Record the decision in the evaluation notes, not in the raw pilot export tree.

## Common decisions

- `include`: the gap is known and does not change the cycle decision
- `flag`: the cycle is usable, but the gap should be visible in reporting
- `exclude`: the gap is too large or too central for the intended analysis

## Rule of thumb

If the gap would force you to reconstruct raw evidence from memory, the missingness should stay visible and the reconstruction should not happen.
