# ACP Pilot Democracy Packs

This directory contains reusable civic and governance scenario families for demo or pilot cycles.

Democracy packs are a stronger layer above prompt packs:

- each file encodes a repeatable democratic coordination pattern
- each pack exposes reusable knobs instead of only one-off scenario details
- each pilot pack has a matching evaluation companion under `../../evaluation/democracy-packs/`

Pack rules:

- each file is a stand-alone pilot scenario family
- each pack should read as a real civic decision, not a generic brainstorming prompt
- each pack should make the reuse boundary explicit enough for later prompt-pack derivation

Current set:

- `civic-participatory-budget-prioritization.md`
- `civic-public-hearing-routing.md`
- `civic-council-agenda-triage.md`
