# ACP Pilot Prompt Packs

This directory contains scenario prompts for civic and governance demo or pilot cycles.

Pack rules:

- each file is a stand-alone pilot scenario
- each pilot pack has a matching evaluation companion under `../../evaluation/prompt-packs/`
- each pack should read as a real civic decision, not a generic brainstorming prompt

- `civic-public-hearing-routing.md`
- `civic-school-board-tradeoff.md`
- `civic-emergency-response-brief.md`
- `civic-procurement-oversight.md`
