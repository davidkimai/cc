# Export Review Checklist

Use this checklist when reviewing Relay exports for a demo, pilot, or fellowship deliverable.

## Analysis export

- [ ] Cycle snapshot is visible at the top
- [ ] Headline metrics are easy to scan
- [ ] Interpretation aids help a reviewer understand what the metrics imply
- [ ] Condition-specific context is present
- [ ] Contributions are listed clearly

## Audit export

- [ ] Audit and telemetry counts are visible
- [ ] Entries are ordered and readable
- [ ] Raw details are preserved without making the document unusable
- [ ] A reviewer can inspect operator actions and participant events quickly

## Minimal export

- [ ] Snapshot is concise
- [ ] Core cycle counts are present
- [ ] Artifact counts are present for quick triage
- [ ] The export would make sense in a Slack message, issue comment, or demo handoff
