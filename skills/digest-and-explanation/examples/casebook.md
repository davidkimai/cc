# Digest And Explanation Flagship Casebook

## Happy path

Every digest item has source contribution, explanation text, and a routing explanation grounded in criteria and critic output.

## Failure path

A digest item says "everyone agrees" when the source thread contains unresolved disagreement. Block release and revise.

## Ambiguity / escalation path

An explanation is plausible but not traceable to routing factors. Escalate to operator review rather than inventing rationale.

## Anti-pattern

Do not improve legitimacy by writing smoother prose than the evidence supports.

## Flagship relevance

This is an S4 skill because participant-facing explanations are where ACP's auditability becomes legible.
