# Deliberation Cycle Casebook

## Happy path

An intervention cycle is `submission_closed`; the operator runs routing, reviews digests, releases, collects reflections, and archives with audit evidence.

## Failure path

The operator asks to release digests while the cycle is still `submission_open`. Stop and report the lifecycle blocker.

## Ambiguity / escalation path

The cycle has submissions closed but no participant roster. Escalate because condition comparability and participant views cannot be trusted.

## Anti-pattern

Do not manually set status to `archived` to make a demo look complete.
