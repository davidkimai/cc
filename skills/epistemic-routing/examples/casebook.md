# Epistemic Routing Flagship Casebook

## Happy path

The cycle is `submission_closed`, routing produces recipient-conditioned decisions, bridge exposure stays within budget, and Engine V2 critics report low risk.

## Failure path

Routing decisions repeat the same dominant concern while excluding a late minority-salience contribution. Recommend revision and omission review.

## Ambiguity / escalation path

The bridge item is relevant but could be tokenistic. Escalate to fairness review before release.

## Anti-pattern

Do not route the most emotionally salient comments to everyone and call that democratic attention coordination.

## Flagship relevance

This is an S4 skill because it demonstrates ACP's core claim: bounded, contestable attention allocation under load.
