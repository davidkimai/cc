# Pilot Analysis Casebook

## Happy path

Baseline and intervention cycles share participant and contribution counts; metrics and exports exist; the summary uses bounded prototype language.

## Failure path

Intervention has more contributions than baseline. Mark comparability failure before interpreting deltas.

## Ambiguity / escalation path

Telemetry is present but sparse. Escalate before using engagement metrics as evidence.

## Anti-pattern

Do not claim field efficacy from synthetic benchmark or tiny pilot metrics.
