# Omission Critic Casebook

## Happy path

Selected digest items cover every material issue cluster and preserve unresolved questions.

## Failure path

The only tenant-displacement comment is excluded while redundant development-support comments are selected.

## Ambiguity / escalation path

An omitted issue is relevant but outside the cycle prompt. Escalate for facilitator judgment.

## Anti-pattern

Do not add low-relevance items merely to make the digest appear balanced.
