# Abstention And Escalation Casebook

## Happy path

Critic risks are low and confidence is high, so the recommendation is release.

## Failure path

Omission severity is high, so the recommendation is abstain until review.

## Ambiguity / escalation path

Fairness severity is medium and explanation faithfulness is uncertain. Recommend facilitator review.

## Anti-pattern

Do not release because the output is polished when critic confidence is low.
