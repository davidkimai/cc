# Fairness And Contestability Casebook

## Happy path

Bridge items are relevant, bounded, explained, and traceable to source contributions.

## Failure path

The only minority-salience item appears as a token bridge without explanation.

## Ambiguity / escalation path

The digest is balanced by topic but explanations imply neutrality the evidence cannot support.

## Anti-pattern

Do not call an output fair because it contains one dissenting item.
