# Overload Governance Casebook

## Happy path

Every digest stays within `maxDigestItems` and bridge exposure stays within `maxBridgeItems`.

## Failure path

A participant receives too many routed items. Block release and revise the digest set.

## Ambiguity / escalation path

Reducing load would drop the only minority-salience item. Escalate to omission/fairness review.

## Anti-pattern

Do not treat shorter output as better if it erases unresolved questions.
