# Participant Web Operator Casebook

## Happy path

The preflight reports readiness, participant view matches server state, and the browser flow renders the correct condition surface.

## Failure path

The UI shows a digest before release. Stop and report server/browser lifecycle mismatch.

## Ambiguity / escalation path

The page renders but participant identity is unclear. Escalate before recording UI evidence.

## Anti-pattern

Do not click through participant actions just to make screenshots look complete.
