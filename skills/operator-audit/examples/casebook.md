# Operator Audit Casebook

## Happy path

Cycle state, audit events, telemetry, metrics, and exports agree; the review summary names the evidence paths.

## Failure path

The export claim exists but no export artifact was generated. Mark the claim unsupported.

## Ambiguity / escalation path

Telemetry is partially missing. Escalate before using engagement metrics.

## Anti-pattern

Do not regenerate evidence after seeing a bad result unless the failed artifact is preserved.
